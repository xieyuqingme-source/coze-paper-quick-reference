# Coze 论文速记工作流

一个用于自动整理学术论文的 Coze Workflow。

## 功能

将论文 PDF 或 Word 文档输入工作流后，自动生成一份结构化的「论文速记卡」。

主要包括：

- 论文基本信息
- GB/T 7714 引用
- APA 引用
- 文中引用
- 论文摘要中文翻译
- 核心问题
- 核心方法
- 核心假设 / 研究思路
- 主要结论与观点
- 建议 / 展望
- 局限性 / 担忧
- 术语对照表

生成的内容可以进一步写入飞书文档，方便长期保存和快速回顾。

## 工作流

```text
论文 PDF / Word
      ↓
文件解析
      ↓
AI 整理
      ↓
生成论文速记卡
      ↓
写入飞书文档

下载
点击仓库中的：
Workflow-thesis_1-draft-9128.zip
即可下载工作流。
使用方法
1. 下载工作流文件。
2. 将工作流导入 Coze。
3. 根据自己的使用环境配置相关节点。
4. 上传论文 PDF 或 Word 文档。
5. 运行工作流。
6. 查看生成的论文速记卡。
适用场景
适合用于：
- 日常论文阅读
- 文献整理
- 学术研究
- 建立个人论文知识库
- 快速回顾已经读过的论文
- 写作时快速查找论文引用信息
关于这个工作流
这个工作流的定位不是生成一份很长的论文分析报告，而是制作一张「论文速记卡」。
核心目标是：
以后不重新读论文，也能快速想起这篇论文讲了什么；需要引用时，可以直接复制引用信息。

因此，工作流主要记录论文原文明确表达的内容，不主动进行额外的评价、批判或延伸分析。
注意事项
- 不同 Coze 环境、插件或模型配置可能需要进行相应调整。
- PDF 如果存在扫描、复杂排版或文本识别问题，可以尝试先转换为 Word 文档，再输入工作流。
- 本工作流主要用于个人学习与研究，也欢迎根据自己的需求修改和完善。
